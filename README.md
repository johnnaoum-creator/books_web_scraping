# Books Web Scraping Project

## Overview

This project uses Python to scrape book information from [Books to Scrape](https://books.toscrape.com/), a website designed for web scraping practice.

## Project Objectives

- Extract book information from website pages.
- Collect book names, categories, ratings, prices, and availability.
- Organize the extracted information into a structured dataset.
- Export the results to an Excel spreadsheet.

## Data Collected

- Book Name
- Category
- Rating
- Price
- Availability

## Tools and Technologies

- Python
- Jupyter Notebook
- Requests
- BeautifulSoup
- Pandas
- Excel

## Repository Contents

- `books_scraper.ipynb`: Jupyter Notebook containing the scraping code.
- `books_data.xlsx`: Excel file containing the extracted dataset.
- `requirements.txt`: Required Python libraries.

## How to Run

1. Clone or download this repository.
2. Install the required libraries using the following command:

   `pip install -r requirements.txt`

3. Open `books_scraper.ipynb` in VS Code or Jupyter Notebook.
4. Run the notebook cells in order.

## Output

An Excel spreadsheet containing the extracted book information.
